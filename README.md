# Skills

个人和团队可复用的 AI 技能。

## 公共事业管理出题技能

[技能入口](public-service-question/SKILL.md)

结合豆包强弱点笔记与历史题单，制作国内公共事业管理专家级评测题目。包含完整出题流程、项目规范、24条历史题单、能力笔记、题目模板及最后去AI味要求。历史资料基线日期为2026-11-09。

### 安装

下载或克隆本仓库，将 `public-service-question` 整个文件夹放入 Codex 的个人技能目录：`$CODEX_HOME/skills/`。未设置 `CODEX_HOME` 时使用 `~/.codex/skills/`。安装后在新会话中使用。

也可以让支持 GitHub 技能安装的助手安装本仓库中的 `public-service-question` 目录。

### 使用

在你希望保存题目的项目目录打开会话，然后输入：

> 用公共事业管理出题技能进行出题。

默认自主选择方向并完成一道题，读取能力笔记和历史题单，在当前项目自动创建：

```text
项目目录/
├── 笔记.md
├── 项目文档/
│   └── 已出题题单.md
└── 题目收集/
    └── YYYY_MMDD_序号/
        ├── 题目.md
        ├── 附件/
        └── 出题记录.md
```

必要时另写待补附件说明。题目保存后同步项目题单，并执行最后去AI味。默认不调用豆包实测，未经实测的难度状态为“待实测”。

也可指定方向或目录：

> 使用 $public-service-question，在当前项目出一道供水领域题目。

### 按需读取与子智能体

主智能体负责查重、选题、统一制题和最终验收。独立探索、材料核读或复核确有收益时，按需使用子智能体，不固定数量。子智能体只读取任务所需规范并回传结论、证据位置及未决问题；正式题目和项目记录由主智能体统一修改。环境不支持子智能体时，顺序执行，质量要求不变。

新题启动读取核心流程、题单及能力笔记，相同的随包与项目记录只读一份。评分、HTML和润色规范在对应阶段读取，培训指南和历史案例保留为参考，不再默认全读。指定旧题仅核验修改影响的环节。

### 资料维护

新项目自动继承随包题单和笔记。已有项目保留新增记录，不以旧快照覆盖。团队需要共享或同步最新项目题单和笔记，技能安装本身不会自动同步同事后来出过的题。

重新发布技能时，将最新整理后的题单、笔记及规范同步到 `references/`。历史题包、答卷和临时缓存不包含在技能中。修订旧题需额外提供对应题包。

运行环境需提供联网检索、文件读写及相应文档阅读工具。已完成技能格式、文件引用和十二字段模板检查，并进行四种使用情景的独立静态审阅；尚未进行新版完整出题流程的效果实测。
