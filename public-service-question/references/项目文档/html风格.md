# HTML 附件制作风格

适用于将公开网页整理为可离线阅读的 HTML 输入附件。以完整、准确的正文为基础，去除网站杂项，重新排版为简洁、美观、易读的内容页。官方原始 PDF、Word、Excel 无需套用此样式。

## 内容与来源

- 提取并完整保留与该材料有关的正文、条款、文号、日期、落款、注释及附件链接。不得用摘要替代原文，不改变数字、条件、适用范围或限定语。
- 去除网站导航、搜索框、登录入口、分享按钮、访问统计、广告及无关页脚。多个相关通知或解读在同一网页中发布时，应完整保留，按原顺序分节呈现。
- 可以合并多余空白、删除重复展示的标题、调整段落和标题层级，但不能改写正文含义或加入解题提示、标准答案、评述。
- 页面最上方用一小行文字标注：`原网址：https://……`。网址应完整显示，并可点击访问原页面。
- 不在页面添加“离线整理版”“网页转换版”“非官方原始文件”等提示、徽章或横幅。文件的整理性质在题目附件清单、来源记录中如实说明，不冒称原始下载文件。
- 标题下可列发布机构、发布日期及文号，必须来自原材料；发布日期、成文日期、落款日期不一致时，不自行混同。
- 原网页附件链接应保留。对应文件已随题提供时，优先使用可用的相对路径链接；其他链接保留完整原网址，不伪造下载状态。

## 页面布局

采用浅灰背景、白色正文卡片、深色文字。页面不放封面图、装饰插画、渐变横幅或大块彩色背景。

- 页面内容最大宽度约 `920px`，居中显示。
- 来源行位于正文卡片上方，字号 `12px`，灰色，长网址允许换行。
- 桌面正文卡片内边距约 `46px 58px 52px`，圆角约 `12px`，细浅灰边框，可有极淡阴影。
- 标题区与正文之间使用一条浅灰细线和适量留白。
- 窄屏下卡片左右外边距约 `10px`，内边距约 `28px 22px`，避免横向滚动。

## 字体与层级

- 使用系统无衬线字体，中文优先采用微软雅黑或思源黑体，不依赖联网加载字体。
- 正文字号约 `16px`，行高约 `1.95`，文字颜色可用 `#263445`。
- 主标题约 `26px`，行高约 `1.65`，字重约 `650`，颜色可用 `#18324b`。窄屏主标题约 `22px`、正文约 `15px`。
- 发布信息约 `13px`，文号约 `14px`，使用较浅的灰蓝色。
- 二级标题约 `20px`，三级标题约 `17px`；按原文结构设置，不把普通长段落整体变成标题。
- 正文段落间距约 `20px`。签署机构与落款日期可右对齐，保持原有对应关系。
- 链接使用克制的蓝色与浅色下划线，能辨认为链接即可。
- 保留原文列表编号。原文含必要表格时保留表格及表头关系，不为了视觉统一破坏数据结构。

## 离线与实现要求

- 使用 UTF-8 编码，设置 `lang="zh-CN"`、页面标题和移动端 viewport。
- CSS 内嵌在 HTML 中；正文阅读不依赖 JavaScript、外部样式、在线字体或网络接口。
- 使用 `header`、`main`、`article`、标题、段落和列表等清晰结构，避免沿用原网站复杂布局。
- 必要的原文图片不得漏掉；下载并核验后，须以带正确 MIME 类型的 Base64 data URI 直接嵌入 HTML（如 `src="data:image/png;base64,…"`），使单个 HTML 文件即可完整离线阅读。不使用网络图片地址或外置图片目录作为正文图片依赖，也不另交重复图片文件。保留原图内容、分辨率及清晰度，图片包含关键文字或数据时，不以猜写文字替代。该要求不改变 PDF、Word、Excel 等独立附件的链接方式。
- 离线阅读不需要登录。点击原网址或未随题下载的外部附件时才需要联网。
- 可提供简洁的打印样式：移除背景、阴影和多余边框，保留来源、标题及正文；无需额外交付网页 PDF。

## 交付前检查

1. 与原网页逐段核对正文，确认数字、条款、日期、落款和必要附件信息未遗漏或改写；仅空白和排版差异可忽略。
2. 检查顶部只有一行来源说明，格式为“原网址：……”，没有额外版本标签。
3. 用浏览器检查约 `1280px` 桌面宽度和 `390px` 窄屏宽度，确认无文字裁切、重叠或横向溢出。
4. 将 HTML 单独复制到不含配套图片的目录，断网或禁用外部请求后检查完整正文及全部内嵌图片仍可阅读；核对图片数量、格式、解码后的原图内容和清晰度。另随题提供的独立附件链接在完整题包中须可用。
5. 同步更新题目中的附件文件名、格式、来源及状态，移除已被替换的网页 PDF，避免重复投喂。
6. 在交付清单中如实注明 HTML 为官方网页正文提取并重新排版的文件；标准答案与制作检查记录不混入输入附件。

## 版式依据

按本文件的布局、字体和离线要求制作，不依赖原项目中的历史附件路径。
