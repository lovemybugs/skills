# 豆包解题强弱点与出题笔记

依据已有答卷评价归纳，不代表所有任务中的固定表现。后续只合并补充新的能力发现，不追加单次评分记录、重复结论或大段案例数据。

## 强项

1. **政策检索与规则整理较强。** 能识别版本、批复效力、身份分类和常见例外，单纯增加政策数量或让其介绍处理流程，难度有限。
2. **明确参数下的计算较强。** 能完成长现金流、水量重建、递推、反解阈值、联合约束、向上取整和扣除持续进水的恢复计算；增加公式和计算链长度不保证更难。
3. **具备对象和边界意识。** 能区分部分企业、批次、断面及统计口径，也能发现部分模型问题；不能笼统归为“不会看材料、不会守恒”。
4. **文稿组织较完整。** 能制作正式报告，组织采用、修订、补证及责任分工；章节齐全和一般风险提示容易完成，不宜占主要分值。

## 弱项

1. **跨附件证据整合不稳定。** 容易漏掉细表、反馈及修订内容，把“没找到”写成“未披露”，或发现更正却未同步到正文与结论。重点考查分散材料是否共同支撑同一个判断。
2. **可比口径与分母核验不彻底。** 对象、期间、含税口径、闰年和工作日可能未统一；遇到差异会先猜时点或版本原因。能算总量，却可能漏掉单位产出成本等会改变绩效判断的指标。
3. **数值正确，业务含义仍可能错误。** 累计乘车人次不等于同时在车人数，预算额度不等于可支配现金，名义容量不等于可用能力，综合评价也不能直接移作单项结论。重点考查指标究竟能证明什么。
4. **证据与假设的适用性审查偏弱。** 会摘录监测值、收入预测或成本参数，却不充分核查代表性、重复计入、收入归属及异常降本依据。应让证据决定参数能否采用，并检验假设变化是否使结论翻转。
5. **发现疑点后，定量证明常未完成。** 能指出模型或数据异常，却可能不复核公式、几何条件，或未用舍入误差上界、质量守恒和数量级比较排除原解释。不能把定性怀疑等同于已证明错误。
6. **跨时间、情景和节点的一致性较弱。** 可能用年度余额证明付款日安全、用多年平均证明逐年保障、把互斥情景相加或串联来源重复累计，也可能局部改数后未更新下游和摘要。
7. **分析中的限制未贯彻到执行结论。** 会一边提示证据不足一边建议沿用，或把筛查阈值写成实际放行条件。重点检查规则是否改变方案，未决问题是否对应具体补证、责任、验收条件及采用限制。
8. **明确交付要求仍会漏项。** 基础数据与主要结果正确，也可能少写差额、负荷率或衔接解释。这属于覆盖度问题，须与计算、模型和业务判断错误分开，不能仅凭漏项造成的低分认定题目很难。

## 出题提醒

1. **围绕真实决策形成依赖链。** 让材料核验影响参数选择，参数影响测算，测算与证据共同决定最终方案。主要分值放在上述薄弱环节；附件数、篇幅、术语和格式不构成有效难度。
2. **明确任务，不提供答案式清单。** 写清对象、范围和交付义务，让模型主动识别问题；采用原件中的确定案例，避免自选简单例子或大量占位。材料必须可读、可定位，真实缺证允许给出有依据的条件结论，不强求编造答案或预设必须找错。
3. **评分考查独立实质判断。** 事先固定标准，不捆绑大量无关细节，不事后加权压分。接受等效推导与有效分支，通读全文认定已完成内容；保护正确承接上游数值的后续计算，独立的业务错误另行评价。
4. **以复测校准难度。** 出题前定位证据、独立复算并检查答案自洽；低分需结合失分原因判断，不能把小漏项、缺材料或下载障碍当成推理难度。新题是否达到分数、时长或步数目标，须由新答卷验证。
