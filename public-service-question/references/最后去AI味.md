# 最后去AI味

每次交付前执行，包括新题和旧题修订。新题先完成实质验收，纯文字修订直接进入本环节。直接修改本题原目录的 `题目.md`。范围为题干、考点、作答思路和文字标答。输入原件保留原样，历史题按用户指定范围处理。技能维护只修改技能本身。

## 交付文字要求

题干写成业务交办，考点写正确应答，标答写结果、依据和处理意见。读者应直接看到“做什么、采用什么条件、怎样计算、由谁处理”。

1. **清除防御性表述。** 自撰正文中的“不得、不能、不是、不代表、不等于、不意味着、不构成、不应、禁止、不要、并非、而非”等表述，在交付前删除或改写。将必要限制写成对象范围、适用条件、数值上下限或处理动作。整句改写，避免替换成另一种否定说法。
2. **删掉免责与重复提醒。** “不代表真实委托”“仅供参考”等出题者自我说明从题干移除。演练性质、合成参数和事实来源在首次出现时简明交代一次。题干、思路和标答分别承担各自任务，减少对同一风险的反复提醒。
3. **保留题意。** 资金用途、法定程序、事实与假设的区别、互斥情景、容量限制和证据不足，都应有清楚的正面表达。数学上的“不可行”、事实上的“未披露”等可准确描述结果，逐段审读应关注句子的作用。清理目标是表达清晰，完整保留业务条件和判断含义。
4. **补证写到动作。** 写明谁提供什么资料、核对什么、何种条件满足后作何处理。证据不足的结论落实为采用范围或后续动作。
5. **减少解题提示。** 题干保留任务和完整输入。把“不得误用某分母”“不能重复扣减”等防错提醒从题干移除，让作答者依据材料完成判断。模型定义确有需要时，直接交代统计范围、归属或计量方式。考点和标答直接写正确口径及对应结果。
6. **整理句子。** 自撰中文正文用短句和必要的编号组织。去掉机械排比、连续设问、重复总结和空泛过渡。分号改为按句意拆分的句子，分号或术语替换只算局部编辑。专业简称和符号首次出现时简要说明。
7. **固定原文。** 完整保留模板评分规则、分值、容差和承前计算保护。原始附件、文件名、网址、公式及必须准确保留的名称保持原样。自撰解释按上述规则清理。

## 改写示例

| 待清理表述 | 直接表达 |
| --- | --- |
| 禁止从其他账户补差。 | 全部支出由本情景预算承担。 |
| 不能将期末率代替年均率。 | 年均率按12个月月末值计算。 |
| 该余额不是可直接使用的预算。 | 使用该余额前，由资金管理主体核定用途并按权限审批。 |
| 不能据此认定当年支出。 | 由项目单位提供付款日期和分类台账，核定支出归属年度。 |
| 本题不代表有关单位提出了真实委托。 | 本题为预算审查演练。 |
| 不得把未收金额重复扣除。 | 题干交代收入和减值的计量定义，标答写出正确公式。 |
| 低于该金额不能满足条件。 | 满足全部条件的最低预算为该金额。 |

## 最后检查：审读、扫描、复核

1. **逐段审读四个字段。** 先删除无作用的句子，再改写必要条件。检查重复、自我辩解、预告错法和解法泄露。连同前后文一起修改，保持因果关系及业务语气。
2. **保存后扫描原文件。** 从技能目录运行以下命令，题目路径使用本轮实际路径：

   ```bash
   python3 scripts/check_final_wording.py /项目绝对路径/题目收集/编号/题目.md
   ```

   脚本只读四个文字字段，输出命中词、段落位置和上下文。命中项逐条修改，再扫描到零命中。脚本仅豁免与模板完全一致的评分规则开头。文件缺失或字段错误时先修复检查入口。代码提供词语检查，段落质量由主智能体审读。
3. **重新读取保存结果。** 对照改前版本，核对日期、主体、参数、公式、数值、分值、容差、证据位置及开放结论的成立条件。确认十二字段、单一表格和 `<br>` 格式，检查是否误删约束或增加评分义务。发现实质变化时返回相应求解和复核环节。
4. **同步交付物。** 如已有压缩题包或其他交付副本，用最终原文件更新并核对。题单与出题记录据实际结果登记。记录“逐段审读完成、原文件扫描零命中、改后实质条件核对完成”及有影响的修改即可。读取本规范、词数下降或脚本通过，均只对应各自环节。

字眼清理适用于交付正文，技能内用于说明问题的示例保留。执行本环节即可完成常规文字修订，按已有授权直接改写。
